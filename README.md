# 📘 Digital Signal Processing

- **University:** University of Trento
- **Professor:** Libertario Demi
- **Academic Year:** 2022-2023
- **Credits:** 9 ECTS
- **Grade:** 28

## 🗒️ Course Description

This course covers the fundamentals of Digital Signal Processing, starting from  discrete-time signals and systems and analyzing discrete-time linear time -nvariant systems, all the way to DTFT, DFT and Z-transform, ending on the design of FIR and IIR filters.
